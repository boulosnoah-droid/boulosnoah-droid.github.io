Cursus dans Claude

Demande à Claude ce que tu as à faire, tes prochains examens, ou d'ajouter un devoir : tout se retrouve dans l'app.

Android, iPhone, web, Windows : le connecteur

Sans rien installer : ajoute Cursus comme connecteur dans Claude. Il marche partout où tu te connectes à Claude (application Android ou iPhone, site web, ordinateur).

  1. Dans Claude : Paramètres › Connecteurs › Ajouter un connecteur personnalisé.
  2. Colle cette adresse :

    https://cursus.babatos.workers.dev/mcp
  3. Claude te renvoie vers Cursus : connecte-toi avec le même compte que dans l'app et autorise.

Il faut un abonnement Cursus actif (ou un code promo) sur ce compte. Selon ton forfait Claude, les connecteurs personnalisés peuvent demander un abonnement Claude payant.

Ouvre cette page depuis l'app

Dans Cursus : Réglages › Connecter Claude › Envoyer à mon ordinateur. Le lien reçu relie Claude à ton compte.

Ouvre ce lien sur ton ordinateur

L'extension s'installe dans l'app Claude pour Mac ou Windows. Envoie-toi ce lien (AirDrop, Messages, e-mail) et ouvre-le sur l'ordinateur.

  1. Si ce n'est pas déjà fait, installe l'app Claude pour ordinateur et connecte-toi : claude.ai/download
  2. Télécharge ton extension Cursus :

    Télécharger Cursus pour Claude ✓ Téléchargé
  3. Ouvre le fichier « Cursus.mcpb » téléchargé (double-clic). Claude s'ouvre : clique sur « Installer ». Si Claude demande une clé, laisse vide : elle est déjà dans le fichier.
  4. C'est prêt. Dans une nouvelle conversation, essaie : « Qu'est-ce que j'ai à faire demain ? », « Quels sont mes prochains examens ? » ou « Ajoute un devoir de maths pour jeudi : exercices 4 à 8 ».

Ce lien et le fichier contiennent ta clé personnelle : ne les partage avec personne. Ils ne donnent accès qu'à ton compte Cursus.
