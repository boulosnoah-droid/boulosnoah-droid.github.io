Cursus dans Claude

Demande à Claude ce que tu as à faire, tes prochains examens, ou d'ajouter un devoir : tout se retrouve dans l'app.

Ajouter Cursus à Claude

  1. Clique sur « Ajouter Cursus à Claude » : la page de Claude s'ouvre (dans le navigateur, sur téléphone) avec le connecteur déjà rempli. Connecte-toi à Claude si on te le demande.
  2. Vérifie le nom et l'adresse, puis valide avec « Ajouter ».
  3. Clique sur « Connecter » et connecte-toi avec le même compte que dans Cursus. Le connecteur apparaît ensuite aussi dans l'app Claude de ton téléphone.

Marche avec tous les forfaits de Claude, y compris le gratuit, sur le web, l'ordinateur, Android et iPhone. Il faut un abonnement Cursus actif (ou un code promo) sur ton compte.
