Support

Mise à jour le 1er octobre 2026

Besoin d'aide ?

Un bug, une question, une idée ? Le plus simple : dans l'app, Réglages › Aide — « Signaler un bug » ou « Contacter le support » préparent un e-mail avec la version de Cursus et de ton appareil.

Ouvre ton app Mail.

Questions fréquentes

Comment synchroniser mes appareils (iPhone, Mac, Android, web) ?
Réglages › Synchronisation › Se connecter, sur chaque appareil, avec le même compte. Pour ouvrir ton compte Apple sur le web ou sur Android : sur ton iPhone, Réglages › Synchronisation › « Se connecter aussi avec Google », puis connecte-toi avec Google sur le web ou Android.

Comment restaurer mon abonnement ?
Sur l'écran d'abonnement, touche « Restaurer ». Il est lié à ton compte Apple.

Comment résilier ?
Réglages › Abonnement › Gérer l'abonnement, ou dans les réglages de ton compte App Store.

Comment utiliser un code promo ?
Ouvre le lien reçu, ou touche « J'ai un code » sur l'écran d'abonnement (ou Réglages › Abonnement › Code promo), connecte-toi avec Apple, puis entre le code.

Les notifications n'arrivent pas.
Vérifie qu'elles sont autorisées dans les réglages de l'appareil › Notifications › Cursus.

Comment supprimer mon compte ?
Réglages › Synchronisation › Supprimer mon compte : toutes tes données sont effacées de nos serveurs.
