Support

Mise à jour le 26 septembre 2026

Besoin d'aide ?

Un bug, une question, une idée ? Écris à boulos.noah@gmail.com, nous répondons dès que possible. Indique si possible ton appareil, sa version (iOS, macOS) et ce qui s'est passé.

Questions fréquentes

Comment synchroniser iPhone et Mac ?
Réglages › Synchronisation › Se connecter avec Apple, sur chaque appareil, avec le même compte Apple.

Comment restaurer mon abonnement ?
Sur l'écran d'abonnement, touche « Restaurer ». Il est lié à ton compte Apple.

Comment résilier ?
Réglages › Abonnement › Gérer l'abonnement, ou dans les réglages de ton compte App Store.

Comment utiliser un code promo ?
Ouvre le lien reçu, ou touche « J'ai un code » sur l'écran d'abonnement (ou Réglages › Abonnement › Code promo), connecte-toi avec Apple, puis entre le code.

Les notifications n'arrivent pas.
Vérifie qu'elles sont autorisées dans les réglages de l'appareil › Notifications › Cursus.

Comment supprimer mon compte ?
Réglages › Synchronisation › Supprimer mon compte : toutes tes données sont effacées de nos serveurs.
